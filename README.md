# Кошачий Пинтерест

Это моя реализация тестового задания для стажёрской программы **Учи.ру**. Приложение позволяет просматривать бесконечную ленту котиков, добавлять их в «любимые» и сохранять свой выбор в памяти браузера.

**[Посмотреть демо (GitHub Pages)](https://chashchinavera.github.io/cat-app/)**

---

## 🛠 Технологический стек

Я выбрала этот набор инструментов, так как он максимально соответствует стеку компании и современным стандартам фронтенд-разработки:

* **Framework:** [Next.js](https://nextjs.org/) (App Router) — использование преимуществ серверного и клиентского роутинга.
* **Language:** **TypeScript** — строгая типизация для минимизации ошибок и удобства работы с данными.
* **State Management:** [Zustand](https://zustand-demo.pmnd.rs/) — легкое управление состоянием с поддержкой сохранения данных.
* **Styling:** **CSS Modules** — для изоляции стилей и предотвращения конфликтов классов.
* **API:** [The Cat API](https://thecatapi.com/) — работа с внешними REST-запросами.

---

## 📂 Структура проекта

Архитектура организована по модульному принципу, что обеспечивает чистоту и масштабируемость кода:

* **`src/app/`** — роутинг приложения (App Router). Включает главную страницу (`page.tsx`) и раздел «Любимые котики» (`favorites/page.tsx`).
* **`src/components/`** — библиотека UI-компонентов. Каждый компонент (Card, CardList, Header) инкапсулирует свою логику и стили (`.module.css`).
* **`src/services/`** — `catService.ts` содержит изолированную логику сетевых запросов к API.
* **`src/store/`** — `useCatsStore.ts` управляет глобальным состоянием, включая список избранного и логику бесконечной прокрутки.
* **`src/types/`** — общие интерфейсы и типы данных (например, модель `Cat`).

## ✨ Реализованный функционал

1.  **Две вкладки:** Главная лента («Все котики») и список избранного («Любимые котики»).
2.  **Бесконечная прокрутка:** Реализована через `Intersection Observer API` в компоненте `CardList`. Новые котики подгружаются автоматически, обеспечивая плавный пользовательский опыт.
3.  **Сохранение данных:** Состояние «Любимых» сохраняется в `localStorage` — ваш список не исчезнет при закрытии вкладки или обновлении страницы.
4.  **Адаптивная верстка:** Сетка карточек реализована на `CSS Grid` и корректно перестраивается под любые разрешения экранов (от мобильных устройств до десктопов).
5.  **Clean Code:** Логика получения данных отделена от UI, а управление состоянием вынесено в специализированный стор.

## 🚀 Как запустить проект локально

1. Клонировать репозиторий:

```bash
git clone https://github.com/chashchinavera/cat-app
```

Установить зависимости:

```bash
npm install
```
Запустить проект в режиме разработки:

```bash
npm run dev
```

Открыть http://localhost:3000 в браузере.

## 📦 Деплой
Проект автоматически собирается и публикуется на GitHub Pages с помощью GitHub Actions при каждом пуше в ветку `main`. Настройки экспорта (`output: export`) заданы в `next.config.ts`.
